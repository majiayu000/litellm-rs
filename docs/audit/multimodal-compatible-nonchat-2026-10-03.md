# Multimodal aggregator protocol audit — 2026-10-03

Issue #1429, F11 bounded batch. Baseline `ed1e83ed51757a5a8f9672b8c41b46cda49a8d21`. Covers aiml_api/aiml, comet_api, bytez and poe. No paid calls or live model/account verification; no price-derived callable models.

Decision: adapt the existing embeddings transport and correct confirmed default endpoints. AIML's published embedding schema contains total token usage but no prompt token field; since embeddings have no generated output tokens, normalize an authoritative numeric total to prompt usage. Never invent a total from input length. Existing generic JSON transport, factory/Router, budgets and errors are reused. Native model-run, asynchronous jobs or bot-chat media need separate adaptations, not a new universal framework.

| Selector | Official protocol evidence | Result and remaining limits |
| --- | --- | --- |
| `aiml_api` / `aiml` | Official pinned OpenAPI defines `/v1/embeddings`, text/array input and float-vector response with `usage.total_tokens`; official guides use OpenAI embeddings clients. Voyage-family schemas use `input_type`. | Enable text embeddings on both existing selectors, map task_type to input_type and normalize numeric total-only usage. Dimensions and task modes depend on selected model; token input/base64 output are not validated here. |
| AIML images/audio | Image endpoint exists, but reviewed official response schema lists data/meta without requiring or defining created, whereas examples vary. TTS uses `/v1/tts` with a JSON audio URL; STT uses `/v1/stt/create` with generation_id. | Do not claim current generic image/binary/multipart transports fit those contracts. Missing-created handling and native/async audio adaptation remain outstanding. No silent timestamp fabrication or URL download added. |
| `comet_api` | Official docs define standard embeddings at `https://api.cometapi.com/v1/embeddings`; current catalog default incorrectly used a different `api.comet.com` host. | Fix the base and enable embeddings; preserve explicit custom URLs. Correctly configured token prices remain required. |
| Comet images/audio | Standard synchronous images and speech/transcription/translation endpoints exist, alongside optional async image tasks and many model-native routes. | This audit does not certify media accounting: current speech model page labels token pricing, another references original-provider character pricing; transcription schema only guarantees text, not duration/token usage. Generic image accounting currently estimates request usage rather than settling returned model-specific image tokens. Keep these capabilities undeclared pending clear units/usage and adaptation. This is not a claim the provider lacks media APIs. |
| `bytez` | Official pinned OpenAI example uses `https://api.bytez.com/models/v2/openai/v1`, including OpenAI SDK authentication. Feature extraction/image/audio examples instead use `/models/v2/{model}` with native payloads/results. | Correct the OpenAI base prefix. No independent standard embeddings/images/audio claim. Native model-run transformation and billing remain outstanding; OpenAI chat multimodal input is not evidence for those endpoints. SDK Bearer behavior is retained; no new raw-key fallback. |
| `poe` | Official API docs expose bot names through chat/completions and Responses; image/video/audio bots use nonstreaming chat for best results. File attachments/content differ from standard image/audio responses. | Keep standalone embeddings/images/audio undeclared. Do not route them to chat merely because a bot can create media. Bot-specific billing and conversion remain separate work. |

## Validation

Local HTTP fixtures exercise both AIML selectors and Comet through factory/Router, float vectors, authoritative total-only usage, input_type translation, 400/429 error contracts and rejection of unverified modes. A real AIML gateway test checks missing-price failure, budget rejection before upstream dispatch and settlement from the normalized actual usage. Passed: 25 HTTP/gateway tests; fmt/check; default complete tests (7,132 library passed, 1 ignored, plus integration/doc suites); default and gateway/sqlite all-target clippy; gateway/sqlite complete tests (9,426 library passed, 1 ignored, plus integration/doc suites). Full tests used `--test-threads=2`. No supplier credentials or paid calls were used.
